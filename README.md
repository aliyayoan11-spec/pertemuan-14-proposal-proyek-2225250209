# Proyek Analisis Nilai Siswa

## Deskripsi
Program ini dirancang untuk melakukan analisis data nilai siswa secara otomatis, menghitung rata-rata, menentukan status kelulusan, serta menghasilkan ringkasan statistik yang akurat. Proyek ini dikembangkan untuk memenuhi tugas Pertemuan 15 Algoritma dan Pemrograman.

## Fitur Utama
- Penghitungan rata-rata nilai siswa secara otomatis.
- Penentuan status kelulusan berdasarkan batas nilai minimum.
- Pembuatan ringkasan statistik (jumlah data, nilai minimum, maksimum, dan jumlah siswa lulus).

## Persyaratan (Requirements)
- Python 3.x

## Cara Menjalankan Program
Buka terminal di VS Code, lalu jalankan perintah berikut:
```bash
python main.py
